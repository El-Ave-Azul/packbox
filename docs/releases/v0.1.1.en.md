**Packbox v0.1.1 — Alpha**

*Cells, hardened sandbox, signatures and HTTP remote*

From v0.1.0 to v0.1.1, Packbox went from a "local packager" to a model
mechanically very close to Flatpak —and better on disk. This release closes
nearly every limitation the v0.1.0 listed as pending.

### What's new
- **Automatic cells**: every non-universal library becomes a cell
  (`org.lib.*@hash`) shared across apps; `packbox-gc` removes unreferenced ones.
- **Layers + overlay**: `/app` is composed with `bwrap --overlay` (A = app over
  C = cells; S = host), without copying cells into each tree.
- **Real deduplication**: CDC (content-defined chunking) for large files +
  hardlinks for small ones (threshold tuned to 32 MiB to keep sharing).

### Sandbox (closer to Flatpak)
- **Per-app private HOME**: it no longer touches your real configuration.
- **Filtered D-Bus** via `xdg-dbus-proxy` (by default, only portals and `dconf`).
- **seccomp**: blocks ptrace, bpf, keyring, io_uring, kernel modules…
- **Opt-in X11** with **session autodetection** (Wayland + portals by default).

### Trust and distribution
- **ed25519 signatures** for `.pbox` (`packbox-sign`, `export --sign`, verified on import).
- **HTTP remote** (`packbox-fetch publish`/`fetch`) with **delta** downloads (chunks + cells).
- **`packbox-update`** with chunk delta and **automatic GC**.

### Extras
- Debug symbols split out (**cell-debug**), on demand.
- **Adaptive** compression in `export` (`auto|max|fast|store`).
- `packbox-list` shows **real size and sharing savings**.
- **15 binaries** (was 11).

### Security
- **tar-slip** and **path-traversal** hardening on import; **atomic** writes in the CAS.

### Docs
- README restructured (Spanish main) and translations under `docs/<lang>/`
  (en, fr, de, it, pt, zh, ja, ko).

> **Alpha** — try it on non-critical systems first.
