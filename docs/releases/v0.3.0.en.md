**Packbox v0.3.0 — Beta**

*Granular networking, LRU GC, app metadata and a more compact export*

Jump to **Beta**: the 0.2.x core settles and on top of it come fine-grained
network control, time-based garbage collection and more app metadata.

### What's new
- **Granular networking** (`network` in the manifest): `none`, `limited` or
  `full`. `limited` starts an **internal HTTP proxy** that blocks access to
  private and reserved addresses (RFC 1918, loopback, link-local). It is
  **best-effort**: it only restricts apps honoring `http_proxy`/`https_proxy`.
- **LRU GC**: `packbox-gc --days N` removes, besides unreferenced chunks, those
  untouched for N days.
- **Manifest 1.7**: app metadata (`developer`, `website`, `license`, `support`);
  `network` becomes a string with **backward compatibility** for old manifests
  that carried it as a boolean.
- **Concurrent remote**: `packbox-fetch` downloads missing chunks in parallel
  (worker pool).
- **Signed index**: `packbox-fetch index --sign` builds and **signs** the
  repository catalogue (`index.json` + ed25519); `search` lists it and `install`
  verifies the signature before installing an app by id.
- **`packbox-update --from`**: the updater now pulls **only the delta** (the
  missing chunks) from a remote instead of requiring them in the local store;
  without `--from` it behaves as before (local).
- **Prebuilt binaries**: `./packbox-install.sh --prebuilt` downloads the
  release's binaries (amd64/arm64), verifies `SHA256SUMS` and installs in
  seconds, without compiling or Go (`.github/workflows/release.yml` publishes
  them on a `vX.Y.Z` tag).

### Sandbox
- Opt-in `dbus:session`, `dbus:system` and `net-proxy:` capabilities.
- **Audio** (PipeWire/PulseAudio) and `/sys` as **read-only**.

### Storage
- The **CAS stores chunks raw**: install **hardlinks** them straight into the app
  tree (no copy, no recompression), which is where the real on-disk savings
  between apps sharing libraries come from.
- **Compression lives in the `.pbox` export** (adaptive plan
  `auto|max|fast|store`), not in the store.

### Fixes
- **Reverted the experimental per-chunk Zstd in the CAS**: it made
  `LinkFile`/`RetrieveFile` return compressed bytes and skewed size accounting
  (it broke the `appinstall` and `remote` tests).
- `packbox-run`: the network-proxy startup messages printed literal `\n`.
- **Sandbox PATH**: `/app/bin` was not on PATH, so an app whose launcher is a
  *wrapper* doing `exec <bin>` with no path (e.g. Strawberry) failed with `127`;
  the sandbox now puts `/app/bin` on PATH (the Flatpak convention), as does the
  generated launcher.
- **Less host exposure**: dropped the read-only `/var` bind (its package DBs and
  logs leaked system state) and made `/dev/shm` a **private tmpfs** (no shared
  memory with host processes). `/usr`, `/lib`, `/bin` and `/sbin` stay visible
  (ro): the model reuses host libs and the launcher is bash. Verified: the app
  starts with `/var` absent and `/dev/shm` as tmpfs.
- **App detection**: stopped treating `/usr/lib/<top>` as a *bundle* (it produced
  false "apps" like Go/Qml6 and duplicates), dropped the `/usr/share/<name>`
  candidate (Vim pointed at `/usr/share/vim`), and dedup by **real binary** and by
  **bundle dir** (the two "Firefox" sharing `/usr/lib/firefox` are now one).

### Upgrading from 0.2.x
- `git pull` and rebuild/reinstall. The manifest moves to 1.7; 1.5/1.6 are still
  read.

> **Beta** — try it on non-critical systems first.
